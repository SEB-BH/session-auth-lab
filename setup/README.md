## Objective

In this lab, you will use the **Auth Template** to build a Journal Entries application.

Users should be able to:

* Sign up and sign in using the existing authentication system. (Already included in the auth template)
* Create journal entries.
* Decide whether an entry is **Public** or **Private**.
* View all public entries.
* View only their own entries.
* Edit and delete only the entries they own.

---

# Setup - Clone the Auth Template

Clone the [Auth Template](https://github.com/SEB-PT-9-Bahrain/session-auth-template) repository by following the steps provided in its `README.md`.

Once everything is working, you will use that project as the starting point for this lab.

**CHECKPOINT**: After cloning run the application using `nodemon` and try to sign up and sign in. Check if the app works. If you have any questions ask Omar.
